# B.Tech 2020 Semester 1 Result

## Project Description
This project displays a B.Tech Semester 1 student marksheet in table format using HTML. It represents student examination results in an organized way.

## Technologies Used
- HTML5
- HTML Tables

## Features
- Student Marksheet Table
- Semester 1 Result
- Subject-wise Marks
- Student Result Information
- Organized Table Structure

## How to Run
Open the index.html file in any web browser.
