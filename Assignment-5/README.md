# Coffee Business Landing Website

## Project Description
This project is a coffee business landing website created using HTML and CSS. It represents a coffee shop and showcases its products and business information.

## Technologies Used
- HTML5
- CSS3

## Features
- Coffee Shop Homepage
- Attractive Coffee Images
- Coffee Products Display
- Business Information
- Navigation Menu
- Responsive Design

## How to Run
1. Open the project folder.
2. Open the index.html file in any web browser.

## Project Purpose
To learn and practice HTML and CSS by creating a coffee business landing website.
